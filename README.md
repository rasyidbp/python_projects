## Python Projects

A collection of Python projects built while learning Python.

### Projects

#### [AI Agent](ai/)

A CLI-based AI coding agent that uses an LLM to interact with a
codebase through predefined tools.

#### [Maze Generator & Solver](maze/)

A maze generator and solver built with Python, including maze
rendering and path finding logic.

#### [Asteroids](asteroids/)

A recreation of the classic Asteroids arcade game, featuring
game objects, movement, collision detection, and asteroid splitting.

#### [Web Scraper](scraper/)

A command-line web crawler that crawls a website, parses HTML,
follows internal links, and produces an internal links report.
